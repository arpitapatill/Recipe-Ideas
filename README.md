# 🍳 QuickCook Helper 

**QuickCook Helper** is a smart and simple web application designed to help users find meal ideas quickly based on available ingredients and dietary preferences.  

This app fetches real recipes from the **TheMealDB API**, allowing users to filter results by diet, healthiness, and cooking time.

---

## 🌟 Features

- 🥕 **Ingredient-based search** – Enter ingredients and instantly get matching recipes.
- ⚡ **Quick meal filter** – Find meals that can be made in under 30 minutes.
- 💪 **Healthy option** – Filters meals tagged as “Healthy”.
- 🌱 **Vegetarian mode** – Shows vegetarian-only recipes.
- 🚫 **No dairy filter** – Excludes recipes containing milk, cheese, butter, or cream.
- 🎲 **Random suggestions** – Get random recipe ideas for variety.
- 📱 **Responsive design** – Works smoothly on desktop and mobile.
- 🍽️ **Recipe details** – View ingredients, instructions, and a YouTube video link.

---

## 🧰 Technologies Used

| Technology | Purpose |
|-------------|----------|
| **HTML5** | Page structure |
| **CSS3** | Styling and layout |
| **JavaScript (ES6)** | Logic, event handling, and API integration |
| **TheMealDB API** | Real-time recipe data |
